Lab Inventory System

Laboratory Inventory Management System

Lab Inventory System is a C# Windows Forms application developed to manage laboratory inventory, reagents, companies, test names, indent details, lot numbers, expiry dates, received quantities, stock balances and quality checks.

C# .NET Windows Forms SQL Server ADO.NET

Project Overview

The application helps manage laboratory stock information in a centralized system. It supports recording inventory details, tracking received quantities and balances, and maintaining reagent and test information.

Key Features

  • User Login
  • Main Dashboard
  • Laboratory Inventory Management
  • Reagent and Company Details
  • Test Name Management
  • Indent Number and Date
  • Lot Number and Expiry Tracking
  • Received Quantity and Stock Balance
  • Quality Check Status
  • SQL Server Database Integration
