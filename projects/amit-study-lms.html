WEB APPLICATION

Amit Study LMS

Learning Management System

Amit Study LMS is a web-based Learning Management System developed to manage student learning activities, attendance, e-library, course fees, live classes and administrative operations through a centralized platform.

C# ASP.NET Web Forms SQL Server HTML CSS JavaScript

Project Overview

The system provides separate student and administrator interfaces. Students can access their profile, attendance, learning resources, course fee information and live classes, while administrators can manage users and live class information.

Key Features

  • Student Login and Authentication
  • Student Dashboard
  • Student Profile Management
  • Attendance Management
  • E-Library
  • Course Fee Management
  • Live Class Management
  • Administrator Dashboard
  • Manage Live Classes
  • SQL Server Database Integration
